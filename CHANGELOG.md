# Changelog

## 1.0.0

First public release of Work Hours Tracker.

- Local hours logging, monthly Excel timesheets, PDF invoices and dashboards.
- Blank first-run setup with user-defined rates and invoice details.
- Explicit workbook import with source preservation and local backup.
- Optional private-folder mirroring, mobile HTML exports and weekday reminders.
- Optional desktop AI summaries with confirmation before notes are sent.
- Source setup helpers, isolated Windows builds, portable release ZIPs and checksums.
- Public distribution excludes personal records, configuration, credentials and old builds.
